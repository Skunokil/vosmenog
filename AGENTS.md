# AGENTS.md — agent-os

> **Это методологическое ядро, не продукт.** Репозиторий содержит метод, шаблоны и
> персоны для framework «agent-os». Изменения здесь влияют на контракт работы всех
> проектов, использующих этот метод.

---

## Как используется

- `METHOD.md` включён в `~/.config/opencode/opencode.json` → `instructions[]` —
  грузится всегда, во всех режимах (см. ONBOARDING.md #2).
- `project-slots.template.md` копируется в `<project>/AGENTS.md` при настройке
  нового проекта — туда пишутся команды сборки, миграций, тестов, пути, грабли.
- `EPIC/TASK/BUG` шаблоны копируются в `team-work/<project>/epics/` при старте фазы.

## Если ты здесь — ты в методологическом репозитории

Это не проект, в котором пишут код. Не ищи:
- конфиги сборки/линтера/тестов — их нет;
- CI/CD — нет;
- lockfiles — нет.

Что делать вместо этого:
1. Открыть `METHOD.md` — это твой рабочий контракт.
2. Не редактировать ничего без явного go от Эпира.
3. Если нужен шаблон для EPIC/TASK/BUG — скопировать из `./` в `team-work/<project>/`.
4. Если нужен project-slots — скопировать `project-slots.template.md` в `<project>/AGENTS.md`.

## head-kit/ — зона Минотавра

Файлы для архитектора/толкователя (роль «Минотавр»). Исполнителю здесь делать нечего.

## Что не делать

- Не редактировать `METHOD.md`, `ONBOARDING.md`, шаблоны, персоны, `head-kit/`.
- Не переносить файлы из этого репозитория в проекты без копирования (не symlink).
- Не класть сюда проектные слоты — они в `<project>/AGENTS.md`.
- Не искать здесь тесты, билд, CI — их нет по устройству.
