# EVM 2.0 — публичный каталог Persona Packs (D0.5)

> Статус: документальные пакеты. Не установлен универсальный Composer, не проверены автоматические переключения и загрузка навыков во всех средах.

В открытом каталоге есть ровно два профиля:

| ID | Пак | Назначение | Источник |
|---|---|---|---|
| vosmenog | Восьменог | Напарник по умолчанию для обычной работы, брифинга и сопровождения ЭВМ | packs/vosmenog/pack.json |
| minotaur | Минотавр | Архитектура, исследование развилок, ревью | packs/minotaur/pack.json |

По умолчанию предлагается Восьменог **только в непроектном чате**, где не установлен иной профиль. В проекте сохраняется действующая проектная персона; по явно разрешённому запросу можно выбрать другой доступный профиль.

## Состав пакета

- Манифест с устойчивым id, ссылкой на одну каноническую персону и перечнем доступных по источникам навыков.
- Разделение литературного лора и инструкций рабочего поведения.
- Привязка к среде через адаптер; встроенные возможности среды проверяются отдельно.
- Session Record остаётся тем же при смене персоны.

Формат: PACK_CONTRACT.md. Роутер для ChatGPT: ../adapters/chatgpt/PERSONA_ROUTER.md.
Навык создания новой персоны: ../skills/persona-maker/SKILL.md.

Публичный метод не хранит, не перечисляет и не поставляет личные профили установки. Их хранение, подключение и допуски определяет владелец в своём закрытом контуре. Универсальный навык создания персон **не** публикует созданный пакет без отдельного согласования.

## Проверка

1. В каждом публичном манифесте visibility=public и persona_id совпадает с каталогом.
2. Указанные исходники действительно существуют; ссылки читаются в нужном контуре.
3. Роль, голос, доступный skill и реальный runtime — четыре разные сущности.
4. При недоступном источнике переключение не утверждается успешным.
5. Новая персона не заменяет Core, проектные правила, GO или Session Record.

Реальное включение в ChatGPT Custom Instructions и Project Instructions — отдельный проверяемый эксперимент; наличие этих файлов в Git не устанавливает их в пользовательских настройках.
