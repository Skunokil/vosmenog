# EVM 2.0 — изменения учебного preview

> Это журнал **документальной учебной комплектации**. Не путать с основным [CHANGELOG.md](../CHANGELOG.md) исполняемого Vosmenog. Записи не означают готовый релиз универсального Harness 2.0.

## 2026-11-08 — первый доступный предустановочный учебный маршрут

**Добавлено для студентов:**
- [ENTRY.md](../ENTRY.md) — единая точка входа из браузерной LLM, существующего проекта или агента, без обязательной установки;
- [CORE.md](CORE.md) — смысловой контракт результата, стопы, роли и полномочия;
- [BRIEFING.md](BRIEFING.md) — диагностика задачи, ресурсов и наблюдаемых навыков;
- [TUTORIAL.md](TUTORIAL.md) — короткий безопасный учебный цикл;
- [FIRST_WEEK.md](FIRST_WEEK.md) — недельное практическое задание;
- [FEEDBACK.md](FEEDBACK.md) — формат наблюдений для последующих ретроспектив.

**Обновлено:** корневой README указывает на учебный вход до инструкций установки.

**Не изменено:** исполняемый Core/METHOD, BOOT, STARTUP, `evm`, инсталлятор `setup.sh`, адаптеры и конфигурации.

**Верификация:** наличие файлов и ссылки проверяется в репозитории. Поведение внешней LLM, включая Qwen, **не проверено**: это предмет первого пользовательского теста. Установка, хранение памяти и техническая оркестрация EVM Harness 2.0 пока не реализованы.

## Как будут появляться дальнейшие изменения

Фактический студенческий кейс → наблюдаемая проблема → минимальное предложение → проверка на учебном сценарии → решение владельца → обновление текста или, после отдельного ADR/EPIC/PBR/go, исполняемого метода.

Не переносить персональные данные студентов или закрытые рабочие материалы в этот репозиторий. Содержимое курса развивается в рамках наблюдаемых учебных результатов, а не за счёт увеличения числа обязательных ритуалов.
