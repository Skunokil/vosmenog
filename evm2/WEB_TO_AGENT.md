# Из веб-чата в OpenCode

Если у вас уже открыт диалог с помощником, который прочитал эту страницу, напишите «начинаем». Если входите самостоятельно, скопируйте блок целиком в привычный веб-чат. По ходу разговора он подскажет, что вставить в терминал и в какой момент перейти в OpenCode.

**Веб-помощнику:** используй сообщение ниже как сценарий в текущем разговоре. Учитывай уже известную систему и завершённые шаги.

```text
Я впервые запускаю OpenCode на своём компьютере. Проведи меня от открытия терминала до первого разговора с агентом. Говори по-русски, по одному действию за раз. После каждого действия жди моего результата.

1. Начни с двух фраз: что такое терминал и как в этом же окне потом появится агент. Если я уже назвал систему, сразу покажи, как открыть терминал и что туда вставить. Иначе спроси только «У тебя Mac, Windows или Linux?». Слов «версия» и «процессор» в ответе от меня не требуй.

2. Дай один готовый блок команд под мою систему. За одну вставку он должен показать версию ОС, архитектуру компьютера и версию OpenCode, если команда доступна. Для Mac используй в одном блоке:
sw_vers -productVersion
uname -m
printf 'Rosetta=%s\n' "$(sysctl -n sysctl.proc_translated 2>/dev/null || echo 0)"
printf 'AVX2=%s\n' "$(sysctl -n hw.optional.avx2_0 2>/dev/null || echo 0)"
if command -v opencode >/dev/null; then opencode --version; else echo "OpenCode не найден"; fi
Rosetta=1 означает Apple Silicon. Для Intel без AVX2 выбирай baseline.

Для Windows используй в одном блоке PowerShell:
Get-CimInstance Win32_OperatingSystem | Select-Object Caption,Version,OSArchitecture | Format-List
Get-CimInstance Win32_Processor | Select-Object Name,Architecture | Format-List
if (Get-Command opencode -ErrorAction SilentlyContinue) { opencode --version } else { 'OpenCode не найден' }

Для Linux собери такой же короткий блок под обычный терминал. Попроси прислать вывод и сам его разбери.

3. Если OpenCode уже запускается, используй его. Для новой установки выбери один способ без Node.js. На Mac и Linux есть официальный установщик: curl -fsSL https://opencode.ai/v2/install | bash. На Windows, а также если мне удобнее скачать мышкой, дай одну прямую ссылку на подходящий файл из раздела CLI https://opencode.ai/docs/ и одно конкретное действие с ним. Для старого Intel Mac учти версию macOS и сборку Intel (baseline). Если не можешь открыть сайт, укажи точную подпись ссылки на официальной странице. Архив самой программы, если он понадобится, открывается на компьютере. В чат его загружать не нужно. При ошибке разбери её текст. Если совместимость подтвердить не удалось, скажи, на чём остановились.

4. Если номер версии ещё не видели, проверь его через opencode --version или по полному пути к скачанной программе. Помоги создать в моей домашней папке папку VibeProjects и в ней новую пустую папку Proba. Если имя занято, возьми новое. Запусти OpenCode именно в новой папке тем же исполняемым файлом, который показал версию. Если нужна модель, покажи, как выбрать доступную бесплатную в /models. Платёжные данные для урока не нужны. Помоги выбрать агента Plan в моей версии интерфейса.

5. Когда я увижу поле ввода в OpenCode, выдай отдельно текст ниже для вставки туда. Если модель не ответит, помоги разобрать ошибку в веб-чате.

«Это мой первый запуск. Начнём с маленького опыта. Назови учебную папку, в которой открыта сессия. Попроси меня открыть её в Finder или Проводнике, создать внутри пустую папку с любым придуманным названием и написать тебе только “готово”. На Linux подскажи, как открыть файловый менеджер. Дождись меня.

После “готово” посмотри инструментом чтения только список имён в корне учебной папки. Не запускай команды и не открывай файлы или вложенные папки. Скажи, какую папку я создал. Если результат неоднозначен, покажи, что действительно видно. Я сверю название на экране.

Когда я подтвержу совпадение, помоги выбрать мой первый проект, отдельную папку для него и одно из двух правил: только читать или предлагать изменения и ждать моего разрешения на запись. Объясни, как выбранное правило поддержать настройками моей версии OpenCode и что пока держится только на нашей договорённости. На выборе остановись. К установке ЭВМ перейдём, когда я попрошу».
```

После пробы можно [выбрать практики ЭВМ для своего агента](EXISTING_AGENT.md). [Вернуться к началу](../ENTRY.md).
