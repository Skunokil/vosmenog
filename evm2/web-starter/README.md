**Для первого знакомства:** [настройте веб-проект с отдельными файлами](../WEB_PROJECT.md). Ниже сохранена инструкция для тех, кто использует комплект v0.2.

**Для новичка в обычном веб-чате.** Скачайте готовые переносимые инструкции и память; Git, терминал, API и платная подписка не нужны. Комплект не создаёт автоматическую память: источником истины остаются ваши файлы.

**[Скачать Starter Pack ZIP](https://github.com/Skunokil/vosmenog/raw/refs/heads/main/evm2/web-starter/EVM_WEB_STARTER_v0.2.zip)** — это скачиваемый архив, а не страница Markdown.

## Вход одним сообщением
Для чистого Qwen, ChatGPT, DeepSeek или другого чата скопируйте [00_PROMPT_START.txt](00_PROMPT_START.txt) и отправьте первым сообщением. ИИ должен предложить **первым шагом скачать архив**, а не сочинять нормативные файлы с нуля.

## Установка без программ — по одному шагу
1. Скачайте ZIP и распакуйте в личную папку. Не помещайте туда секреты и материалы, которые нельзя передавать выбранной модели.
2. Приложите `01_Instrukciya.md` к веб-чату (или вставьте текст в инструкции проекта, если сервис это поддерживает). Проверьте чтение: попросите назвать первый заголовок, раздел 4 и четыре значения `confirmation`.
3. С помощью ИИ заполните `02_PROJECT_MEMORY.template.md` и `03_SESSION_RECORD.template.md`, сохранив как `PROJECT_MEMORY.md` и `SESSION_RECORD.md`. Сначала научитесь переносить память; к предметной задаче можно перейти после этого.
4. **Сохраните заполненные файлы на своём устройстве**. Подготовленный текст в чате ≠ сохранённый файл; проектные файлы сервиса тоже могут устареть.
5. В новом независимом чате прикрепите инструкцию и актуальные два файла. Отправьте `04_RESUME_PROMPT.txt`; сверьте ответ по `05_TEST_PORTABILITY.md`.

Если сервис не принимает файлы, вставьте их текст в сообщения. Не дублируйте авторитетные документы; короткой заметки может быть достаточно для одноразовой работы.

## Файлы
- `00_PROMPT_START.txt`: вход одним промптом.
- `01_Instrukciya.md`: проверяемые правила переносимой работы.
- `02_PROJECT_MEMORY.template.md`: шаблон долговременных решений и фактов.
- `03_SESSION_RECORD.template.md`: текущая сессия с `classification=undecided`.
- `04_RESUME_PROMPT.txt`: восстановление в новой модели.
- `05_TEST_PORTABILITY.md`: приёмка переноса.
- `MANIFEST.json`: версия и состав.

Нормативы: [ENTRY](../../ENTRY.md), [CORE](../CORE.md), [SESSION_RECORD D0.6.1](../SESSION_RECORD.md). Прототип не заменяет правила вашего проекта, платформы или строгого программного харнесса.

**Границы beta:** ручное обновление памяти, без гарантии доступа к GitHub/вложениям в каждой модели и без автоматической синхронизации. Сообщение ИИ «прочитал» не равно независимой телеметрии. Файлы исходников лежат рядом с ZIP для проверки.
