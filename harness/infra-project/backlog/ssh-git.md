# Backlog: SSH-доступ к GitHub и git-репозитории проектов

**Статус:** черновик (не эпик) · **Источник:** скилл `infra-bootstrap`, шаги 1–2

## Проблема / нужда

Проекты и метод живут на сервере и в GitHub (репозиторий vosmenog — источник
дистрибутива). Без SSH-доступа к GitHub нет автообновления дистрибутива
(`git pull` в `~/agent-os`) и push изменений из рабочих репозиториев.

## Возможные работы

- [ ] Проверить/сгенерировать SSH-ключ (`~/.ssh/id_ed25519`), добавить публичный на GitHub (владелец)
- [ ] Проверить `ssh -T git@github.com`
- [ ] Для каждого проекта: `git init` + remote + ветка `main` + первый push
- [ ] Правило: `.env*` в `.gitignore`, секреты не коммитить

- Кто создаёт приватные репозитории (владелец)
