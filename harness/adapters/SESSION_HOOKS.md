# Session Record hooks — Claude Code и Codex

> **Статус:** opt-in адаптер. Код может создавать запись сессии и метаданные событий. Ни один hook не выдаёт полномочий, не даёт GO, не заменяет native gate и не собирает транскрипты.

## Что происходит

- `SessionStart`: идемпотентно открывает Session Record с `undecided`. У одной и той же сессии после resume/compact сохраняется UID. Внутри `sessions/active/` нет эпика до квалификации.
- `PostToolUse` и `PostToolUseFailure`: в приватный `~/.local/state/evm/traces/<project>/<uid>.jsonl` попадают **только** время, тип события, нормализованный класс инструмента и отметка, что его результат требует независимой проверки. Аргументы и ответы никогда не сохраняются.
- `SessionEnd`: отмечает только событие завершения runtime; **не закрывает и не архивирует** незавершённый документ за агента. При следующем входе можно продолжить его по UID.
- В существующем native Codex, если `sessions/work/<hash>.json` уже ведётся собственным движком, общий адаптер пропускает создание второго Markdown. Существующий native document gate остаётся источником истины.

## Claude Code — явное подключение без повышения прав

После принятия исходников, обновления дистрибутива и проверки новых хуков:

```bash
python3 harness/adapters/claude-code/install.py --session-hooks
```

Команда выполняется из **исходного клона** `Skunokil/vosmenog` после обновления. `~/agent-os/` содержит установленные инструменты, но не обязан содержать исходный установщик. Проверь путь клона.

Подключение добавляет отдельные обработчики в `~/.claude/settings.json` с резервной копией, сохраняя существующие SessionStart/Stop и чужие hooks. Для проверки перезапусти новую сессию и убедись, что указана реальная запись `sessions/active/S-....md`. Для rollback убери только четыре добавленные записи `evm hook ...` из `settings.json` (сделав резервную копию), затем перезапусти клиент. Уже созданные документы не удаляются.

## Codex — шаблон только для review

Референс `harness/adapters/codex/session-hooks.example.json` можно подключать **после** проверки конкретного runtime и его trust-gate. Не копировать поверх чужого `.codex/hooks.json` и не менять глобальный конфиг существующих Минотавра/Зины/Веры. В native LAB и без этого есть document gate; он приоритетен.

## Границы / проверка

- Нет автоматического принятия EPIC/TASK или фиксации пользовательского решения: смысловые события записывает агент.
- Автозапись события инструмента **не** означает, что действие успешно и результат принят.
- Роль, sandbox, sudo, Codex approval и доступ к секретам не меняются.
- При отсутствии доступного planning-root адаптер пишет `not_saved` в контекст на старте; не придумывает путь.
- `evm off` отключает все новые hooks так же, как существующие.
