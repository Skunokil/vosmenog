# {{PROJECT}} — учебный проект курса «Вайбкодинг»

Проект настоящий: код работает, документы пишутся, решения фиксируются. Учебное
здесь одно — темп и то, что агент объясняет каждый свой шаг.

## Что где лежит

| Что | Где |
|---|---|
| Код | эта папка |
| Кейс или описание задачи | `docs/` |
| Эпики, бэклог, журнал спринтов | `~/projects/team-work/{{PROJECT}}/` |
| Правила проекта для агента | `AGENTS.md` |

## Как начать работу

```bash
cd ~/projects/{{PROJECT}}
opencode
```

Первая фраза агенту — не «напиши код», а «давай начнём эпик». Эпик отвечает на три
вопроса: зачем это делаем, что считаем готовым, как проверим. Дальше по методу.

## Что будет к концу курса

- Работающий прототип, решающий одну живую задачу.
- Репозиторий с историей: не только код, но и решения — почему именно так.
- Умение провести следующую задачу тем же маршрутом уже без подсказок.

## Если застрял

- Спроси агента: «объясни, что мы сейчас делаем и зачем» — он обязан объяснить.
- Посмотри `AGENTS.md`: там записано, как агент ведёт себя в этом проекте.
- Принеси затык на встречу группы. Разбор чужого затыка — половина курса.
