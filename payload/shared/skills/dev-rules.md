# dev-rules.md — правила разработки (Минотавр)

> Незыблемые правила, проверенные временем. Персона их не отменяет — она их любит.
> Полный метод (роли, гейты, эпик/таск/баг) — METHOD.md. Проектные правила
> (миграции, контейнеры, ветвление, стили) — <project>/AGENTS.md, не здесь.

## Правило 1 — Рекон перед кодом, всегда
Живой контейнер — единственный источник истины. Не предполагать содержимое файлов,
схему БД, поведение роутов по памяти. Имена таблиц/колонок — из живой схемы
(information_schema), не по догадке. Пути и структуру — из живого дерева.
> Касается и бэклога/багов: Минотавр НЕ заносит задачи и баги по памяти — только после
> рекона, как код. Руки страхуют реконом — но лучше не давать повода.

## Правило 2 — Контроль выводов рук (Восьменога)
Рекон/аудит агента — вход для решений головы, не финальная истина. Ключевые факты,
на которых стоит решение, перепроверять независимо. Агент слаб в многопроходных
рассуждениях — там и ловить (цепочки условий, взаимозависимости, краевые случаи).

## Правило 3 — Итеративный workflow
Команда → вывод → проверка → следующий шаг. Не делать несколько шагов без
подтверждения. Гранулярные коммиты по концерну; код и planning-доки раздельно.

## Правило 4 — Редактирование кода (repr-patch)
Только python3, никогда sed (ломает кириллицу). str.find() + repr() anchor-проверка
+ count==1 assertion ДО записи. После Python — AST-парс, после JS — node --check.
node --check НЕ ловит ReferenceError (выдуманная функция пройдёт синтаксис, упадёт в
рантайме) — существование проверять отдельным grep -c. Anchor не уникален → расширить контекстом.

## Границы (всегда)
- **Секреты / env** — только в конфиге среды, никогда в чат, никогда агенту.
- **Развилки — на берегу, до кода.** Выбор без ответа → стоп, к Эпиру. Эпик с внешней
  интеграцией бьётся на под-треды по точкам перехода.
- **git-push и применение к проду/БД** — go Эпира. Код в рабочей ветке безопасен; применение — нет.

## Проектные правила — в AGENTS.md
Миграции, контейнеры/сервисы, схема ветвления, переиспользование стилей — специфика
проекта. Живут в <project>/AGENTS.md (ведёт Эпир), не в этом файле.
