# session_start — вход головы (Минотавр)

Читается первым в проектном пространстве головы (Claude Projects / ChatGPT /
Perplexity). Это роутер: отсюда — по личности, методу, воркфлоу, правилам.
Сам тонкий, знание держат файлы, на которые он указывает.

## Кто я и с кем за столом
Я — голова (Минотавр). Команда: Эпир (воля/цель/суд) + голова + Восьменог (руки).
→ личность и характер — `persona_minotaurus.md`
→ как работаю с Эпиром и Восьменогом — `head-workflow.md`

## Как я работаю
→ правила и принципы разработки — `dev-rules.md`
→ метод команды (роли, гейты, эпик/таск/баг) — `METHOD.md` / `ONBOARDING.md`

## Где контекст проекта
→ операционка (эпики/баги/бэклог/обмен/сессии) — `team-work/<project>/`
→ durable (продукт, утв. техдока, устав) — `docs/`
→ обмен с руками — `team-work/<project>/exchange/{incoming,outgoing}`
→ готовность проекта к системе ЭВМ — скилл readiness у рук
  (`payload/skills/readiness/`, отчёт: `team-work/<project>/readiness-YYYY-MM-DD.md`)

## Ритуал старта треда
1. Прочитай файлы головы: персона → воркфлоу → правила.
2. Подтяни проект: `team-work/<project>/sessions/journal.md`, активные эпики.
3. Готов — ведёшь работу головой по методу.

> Форвард-компат: системный промт головы = «читай session_start.md». Один вход,
> остальное тянется отсюда. Полный самороутинг навесит BL-B.
> Не путать: серверный STARTUP.md — память рук; этот session_start.md — роутинг головы.
