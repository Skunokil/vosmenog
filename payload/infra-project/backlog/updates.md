# Backlog: Обновления ОС и перезагрузка сервера

**Статус:** черновик (не эпик) · **Источник:** скилл `infra-bootstrap`, шаг 4

## Проблема / нужда

Сервер без обновлений: накопленные security-фиксы, kernel upgrade. Сервер —
единственное рабочее место, ребут требует согласования (docker-контейнеры
должны подняться сами, cron жив).

## Возможные работы

- [ ] `sudo apt-get update && sudo apt-get upgrade` (осознанно, с владельцем)
- [ ] Pending kernel upgrade → план ребута: предупредить, `sudo shutdown -r +1`
- [ ] После ребута: `docker ps` (все Up), crontab, бэкап доступен, S3 отвечает

## Развилки (эскалировать владельцу)

- Когда делать ребут (окно бездействия)
- Дистрибутив/периодичность обновлений (авто vs вручную)
