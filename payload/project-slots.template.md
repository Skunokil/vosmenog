```bash
python3 - << 'PYEOF'

with open(path) as f: src = f.read()
old = '<точная строка>'
idx = src.find(old)
print('found at:', idx)
if idx >= 0:
    src = src.replace(old, '<новая строка>', 1)
    with open(path, 'w') as f: f.write(src)
    print('OK')
PYEOF
```

## Пример заполненного AGENTS.md

```markdown
# AGENTS.md — My App (слоты проекта)

## Для старта (обязательное)

### Стек
- Frontend: React 19 + Vite
- Backend: FastAPI (Python 3.12)
- БД: PostgreSQL 16
- Сборка/тулинг: uv (Python), npm (JS)

### Пути
- Корень: ~/projects/my-app
- Фронт: src/
- Бэк: api/
- Билд: dist/
- Операционка: team-work/my-app/
- Durable: docs/

## По мере необходимости

### Git-состояние
- Репозиторий: да
- Remote: git@github.com:user/my-app.git
- Ветвление: main + feature-ветки

### Билд
```bash
npm run build
```

### Линт / тесты
```bash
npm run lint
pytest
```

### Миграции БД
```bash
alembic upgrade head
```

### Гейты проекта
- Безопасно без go: коммит в feature-ветку, dev-сборка
- Требует go: деплой, миграции в проде

### Грабли проекта
- seed --force без проверки volume = потеря данных
```
