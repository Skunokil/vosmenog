# user-profile.md — личные уточнения и уровень доверия

> Профиль пользователя фреймворка Vosmenog. Живёт в `~/.config/opencode/memory/`,
> защищён от затирания при обновлении (не в cp-списке `update.sh`, раскладывается
> по журнальному паттерну: если есть — не трогаю).
>
> **Не переопределяет METHOD.md.** Профиль делает две вещи:
> (а) уточняет рекон (Правило 1) — чем реконить, какие живые источники;
> (б) выставляет два параметра: `trust_level` (частота согласований) и
>     `detail_level` (детализация комментариев по компетенции пользователя).
> Базовые стопы и принципы метода — в `~/agent-os/METHOD.md`, они не отменяются
> профилем ни при каких настройках.
>
> Оба параметра работают по правилу `min`: итоговое значение = строже (минимум)
> из профиля и опционального слота в `AGENTS.md` проекта. Проект может только
> ужесточить, не ослабить. Нет слота в AGENTS.md → берётся профиль.

---

## 1. Проектные уточнения рекона

Уточнения к Правилу 1 (Рекон перед правкой): какие инструменты/источники использовать
по умолчанию, какие живые системы спрашивать.

```yaml
# Пример:
# recon_tools:
#   - grep -n
#   - information_schema (БД)
# live_sources:
#   - http://localhost:8080/api/docs
```

## 2. Уровень доверия и детализация

Два независимых параметра:
- `trust_level` — частота согласований (по доверию к агенту);
- `detail_level` — детализация комментариев (по компетенции пользователя).

Технические барьеры (периметр `external_directory`, зона безопасности — деструктив,
секреты) стоят на любом уровне: ось крутит разговор, не права. Метод — см. METHOD.md,
«Ось доверия» и «Зона безопасности».

Раскомментируй нужные значения:

```yaml
# trust_level: обучающий     # согласует всё, включая рекон
# trust_level: средний       # согласует изменяющее; рекон свободно
# trust_level: продвинутый   # согласует только зону безопасности (деструктив/секреты)

# detail_level: обучающий    # объясняет каждую команду и её следствия
# detail_level: средний      # объясняет ключевые шаги, без мелочей
# detail_level: продвинутый  # короткие ноты по существу
```

> Деградация: нет `detail_level` → берётся значение `trust_level`; нет обоих —
> базовая планка (обучающий).
>
> **Продвинутый = автоматика в периметре**: согласуется только зона безопасности.
> Полная автоматика (без зоны) — отдельным решением владельца, не через профиль.
